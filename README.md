# Acervo — The Protestant Core

Pinturas em domínio público usadas nos posts do @theprotestantcore.

- Acrescente nomes de arquivos do Wikimedia Commons em `pedidos.txt` e faça push.
- A Action **Baixar pinturas** baixa cada uma para `pinturas/` (com um `.json` de metadados: artista, data, licença, link) e atualiza `acervo.json`.
